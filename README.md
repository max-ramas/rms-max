# 💬 RMS MAKS

**Нативный и лёгкий клиент мессенджера MAX для macOS и iOS: без телеметрии, со сквозным шифрованием между своими и в привычном интерфейсе.**

Написан с нуля на чистом Swift — без Electron, Chromium и сторонних трекинговых SDK. Работает напрямую по протоколам MAX,
не отправляет о вас никаких данных и умеет то, чего нет в официальных приложениях: шифрование переписки на вашей стороне,
блокировку трекеров и открытый исходный код.

> ### 🔒 Обещание о приватности
> RMS MAKS **не собирает** ваши сообщения, контакты, файлы, нажатия клавиш и статистику использования. В клиенте нет аналитики,
> сбора данных об устройстве и фоновых пингов, а запросы к трекерам мини-приложений блокируются. Единственное обращение к серверам RMS —
> проверка новых версий по криптографически подписанному манифесту. Исходный код открыт: это можно проверить.

> RMS MAKS — неофициальный клиент. Он не связан с разработчиками MAX и не одобрен ими.

## Почему RMS MAKS

- **Нулевая телеметрия и блокировка трекеров.** Аналитика, метрики устройства и фоновые отправки вырезаны полностью. Встроенный фильтр
  на уровне транспорта режет трекеры мини-приложений и сторонних сервисов (AppMetrica, MyTracker, Mail.ru, Яндекс.Метрика и другие).
  Список заблокированных доменов виден в настройках, его можно дополнять.
- **Нативный Swift, а не обёртка над браузером.** Приложение компактное: установщик для macOS около 27 МБ, для iOS около 11 МБ, в работе
  на macOS оно занимает порядка 40–60 МБ оперативной памяти. Запускается мгновенно, ведёт себя как родное приложение системы.
- **Сквозное шифрование между своими.** Переписка и звонки между пользователями RMS MAKS шифруются на устройстве отправителя и
  расшифровываются только на устройстве получателя (ChaCha20-Poly1305, ключи на Curve25519, пароль чата через Argon2id).
  Включается переключателем прямо в чате.
- **Знакомый интерфейс.** Трёхколоночная вёрстка на macOS в духе Telegram, нативная навигация на iOS, горячие клавиши, правый клик,
  панель информации о чате, быстрый медиакэш — и ничего лишнего.
- **Открытый код.** Лицензия GNU AGPLv3: код можно читать, проверять и менять, но нельзя забрать в закрытый продукт.

## Возможности

### Чаты и сообщения
- Личные и групповые чаты, каналы с комментариями, папки и фильтры чатов, закреплённые сообщения.
- Ответы, пересылка (в том числе нескольких сообщений сразу), редактирование, удаление у себя и у всех, **выделение нескольких сообщений**.
- **Форматирование как в Telegram**: жирный, курсив, подчёркнутый, зачёркнутый, цитата, моноширинный, ссылки и `@упоминания` — прямо в
  поле ввода, с горячими клавишами (⌘B, ⌘I, ⌘U, ⇧⌘X, ⇧⌘., ⇧⌘M, ⌘K) и меню «Форматирование».
- Нормальное поле ввода: Return отправляет, Shift+Return переносит строку (или наоборот — по настройке).
- **Реакции** с набором, который задан для чата, и **опросы**: создание (анонимные, с несколькими ответами, с переголосованием) и голосование.
- **Отложенные сообщения**: отправка в заданное время, список запланированных с удалением.
- Черновики по каждому чату, повторная отправка при сбое, поиск по чату и по всем сообщениям, темы оформления для каждого чата.
- Статусы: набор текста, «в сети», галочки доставки и прочтения.

### Медиа
- Фото, видео, файлы, голосовые сообщения с формой волны, **видеосообщения-кружки** (запись и просмотр), вставка картинки из буфера обмена.
- **Стикеры и эмодзи**: панель с поиском, управление наборами (добавить по ссылке, удалить), недавние, **анимодзи** (анимация на устройстве).
- **Умный медиакэш** как в Telegram: дисковый кэш с лимитом и очисткой по типам, предзагрузка кружков, голосовых и фото, правила автозагрузки.
- Истории: просмотр и публикация.

### Звонки
- Аудио- и видеозвонки, **групповые конференции по ссылке** (создать, поделиться, войти), демонстрация экрана, история звонков.
- Звонок записывается в ленту чата (длительность, пропущенный, отменённый), звуки дозвона и завершения, как в привычных мессенджерах.
- Шифрованный режим звонка между пользователями RMS MAKS.

### Приватность и безопасность
- **Блокировка приложения** по Touch ID / Face ID; данные сессии и ключи хранятся в системной связке ключей (Keychain).
- Настройки приватности аккаунта MAX: кто может найти вас по номеру, звонить, приглашать в чаты, видеть номер и статус «в сети».
- **Пароль для входа** (двухфакторная защита): включить, сменить, удалить, подсказка и почта для восстановления.
- Прозрачные разрешения: в настройках видно, зачем нужен каждый доступ (уведомления, микрофон, камера, контакты, запись экрана),
  в каком он состоянии и как его включить.

### Интеграция с системой
- Нативные уведомления со звуком, значок в строке меню, счётчик на значке приложения.
- Ссылки MAX открываются в приложении (схема `max://`): конференции, приглашения в чаты, профили, наборы стикеров.
- Панель информации о чате и контакте, меню сообщения с реакциями, быстрый переход между чатами.
- Автоматические обновления с проверкой криптографической подписи.

## Скачать

> Установочные файлы раздаются с официального сервера обновлений RMS. Страница продукта: [rms-ds.com](https://rms-ds.com/en/products/rms-maks).

### macOS (macOS 14+, Apple Silicon и Intel)

1. Скачайте [установщик `.dmg`](https://update.rms-ds.com/get/rms-maks/dmg).
2. Откройте его и перетащите RMS MAKS в папку «Программы».
3. Приложение подписано сертификатом Apple Developer ID и нотаризовано Apple: оно запускается без предупреждений Gatekeeper,
   а дальше обновляется само.

### iOS (iOS 17+, через SideStore)

Сборки для iOS распространяются вне App Store: подписывает приложение ваш SideStore своим бесплатным сертификатом, и на устройстве
нет подписи разработчика RMS. Приложение использует один App ID и не содержит расширений.

1. Добавьте источник RMS в SideStore одним нажатием: [`sidestore://source?url=https://update.rms-ds.com/altstore/rms-maks.json`](sidestore://source?url=https://update.rms-ds.com/altstore/rms-maks.json)
   — или вручную в разделе **Sources**, адрес:

   ```
   https://update.rms-ds.com/altstore/rms-maks.json
   ```

2. Установите RMS MAKS из добавленного источника.
3. SideStore будет сам предлагать свежие версии.

Если нужен только файл: [`.ipa`](https://update.rms-ds.com/get/rms-maks/ipa) (неподписанный).

Подробная пошаговая инструкция по установке SideStore и RMS MAKS: [ipa-install.md](ipa-install.md).

## Приватность

- **Никакого сбора данных.** Сообщения, контакты, файлы, нажатия клавиш и статистика использования не собираются и не отправляются.
- **Прямое подключение.** Клиент общается с серверами MAX и с вашими собеседниками, посредников нет.
- **Проверка обновлений.** Приложение обращается к `update.rms-ds.com` только затем, чтобы узнать о новых версиях, и устанавливает их
  лишь если подпись манифеста верна.
- **Всё локально.** Кэш медиа, черновики и настройки лежат на вашем устройстве; кэш можно ограничить и очистить в настройках.

## Ограничения

- **Уведомления на iOS.** Без сервиса Apple Push (APNs) приложение, установленное через SideStore, показывает уведомления, пока оно
  запущено или активно в фоне. Когда его выгрузила система, уведомления не приходят.
- **Особенности сервера MAX.** Сервер не отдаёт полный список закреплённых сообщений и список «кто просмотрел» в группах, поэтому в
  интерфейсе их нет. Анимодзи доступны не всем аккаунтам: наборы выдаёт сервер.
- **Шифрование — только между пользователями RMS MAKS.** Собеседник в официальном приложении увидит служебный текст, а не сообщение.
- **Язык интерфейса — русский.**
