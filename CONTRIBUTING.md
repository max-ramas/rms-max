# Участие в разработке RMS MAKS

Спасибо за интерес к проекту! Ошибки, идеи и исправления приветствуются.

## Принципы, которые не обсуждаются

- **Никакой телеметрии.** Аналитика, сбор данных об устройстве, трекинговые SDK и скрытые сетевые обращения не принимаются.
  Единственное обращение к серверам RMS — проверка обновлений по подписанному манифесту.
- **Данные пользователя остаются у пользователя.** Секреты хранятся в Keychain, лишних разрешений приложение не требует.
- **Нативный Swift.** Без Electron, веб-обёрток и тяжёлых сторонних зависимостей без веской причины.

## Как предложить изменение

1. Откройте [issue](../../issues) с описанием ошибки или идеи (для крупных изменений — до начала работы).
2. Сделайте форк, создайте ветку и внесите изменения. Сборка — в [BUILDING.md](BUILDING.md).
3. Запустите `swift test`: все тесты должны проходить. Новое поведение покрывайте тестами в `Tests/RMSMaxCoreTests`.
4. Откройте pull request с понятным описанием: что и зачем меняется, как проверить.
